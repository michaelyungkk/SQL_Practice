# Analyst Quest

You can open the app by double-clicking [Open Analyst Quest.bat](C:/Users/micha/OneDrive/文件/SQL Practice Game/Open Analyst Quest.bat).

The launcher will:
- install dependencies automatically if they are missing
- start the local app server
- open the app in your default browser at `http://127.0.0.1:4173`

Manual commands are still available:
- `npm run dev`
- `npm run build`
- `npm run preview`
